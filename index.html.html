API reference
All endpoints are live at http://localhost:8002. Use any REST client or import into Postman.
Layer 1 — Ingestion
POST/ingest/csvUpload CSV → feature store
POST/stream/eventSingle Kafka event
POST/stream/batchReplay event array
GET/feature-storeAll customer vectors
GET/drift-logDrift detection history
GET/event-logRaw event stream log
Layer 2 — Prediction
POST/trainTrain XGBoost + MLP
POST/predict/customerSingle customer prediction
POST/predict/batchScore all customers
GET/predict/stream-triggersScore drift-triggered customers
POST/explainSHAP explanation
GET/metricsModel performance report
GET/reportFull pipeline status
Quick test — curl
# Upload + ingest CSV
curl -X POST http://localhost:8002/ingest/csv \
  -F "file=@telco_demo.csv"

# Train both models
curl -X POST http://localhost:8002/train \
  -F "file=@telco_demo.csv"

# Predict single customer
curl -X POST http://localhost:8002/predict/customer \
  -H "Content-Type: application/json" \
  -d '{"customer_id":"CUST-00003"}'

# Batch score all
curl -X POST http://localhost:8002/predict/batch \
  -H "Content-Type: application/json" \
  -d '{}'

# SHAP explanation
curl -X POST http://localhost:8002/explain \
  -H "Content-Type: application/json" \
  -d '{"customer_id":"CUST-00003"}'

# Kafka event
curl -X POST http://localhost:8002/stream/event \
  -H "Content-Type: application/json" \
  -d '{
    "event_id":"EVT-001",
    "customer_id":"CUST-00001",
    "event_type":"payment_failure",
    "timestamp":"2026-04-26T10:00:00",
    "metadata":{}
  }'
